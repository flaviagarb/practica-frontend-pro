What does consist of?

We start from the basics of programming and will lead you to advanced levels in HTML, CSS, Javascript, React, Servers, Microservices and the tools and technologies necessary for the development of your professional work.

We believe that when it comes to programming there are different levels, from just writing code in a programming language to mastering the process of building functional software that provides a real and usable solution to a problem.

With our course, in addition to having a solid and extensive training in frontend, you will master frameworks and languages for the backend, you will know how to implement a microservices architecture from scratch and scale it according to the needs of each project.
