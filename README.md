# KeepCoding Web Bootcamp XVIII – **Frontend PRO Project**

A hands‑on assignment for the **Frontend PRO** module of KeepCoding’s Web Bootcamp.  
We’ll build a website for the **Quidditch World Cup Final** (Harry Potter universe), starting with plain HTML + CSS and gradually upgrading to a professional front‑end stack.

---
## Getting Started

```bash
git clone git@github.com:flaviagarb/practica-frontend-pro.git
npm install
```

## Tech Stack & Tools

| Area                | Tool |
|---------------------|------|
| Editor              | Visual Studio Code |
| Runtime / Packages  | Node.js & npm |
| Version Control     | Git |
| Language            | **TypeScript** |
| CSS Preprocessor    | **Sass** |
| Bundler             | **Parcel 2** |
| UI Utilities        | **Tailwind CSS** |
